# 사이트 개편 안내 (2026-07-19)

## 1. 자료실 자동발행 (수동 업로드 → 자동)

- 새 파이프라인: `lib/archive-auto-publish.ts` + `/api/archive/auto-publish`
- **매주 월·수·금 00:00(UTC)** Vercel 크론이 자동 실행 (`vercel.json`)
- 동작: 주제 로테이션 선택 → AI 생성 → 메타 분류(블로그/자료실 + 하위분류) → 제목 중복 검사 → 자동 `published`
- 중복 방지 3중 장치:
  1. 주제 풀(18개)이 한 바퀴 돌기 전에는 같은 주제 재선택 안 함 (`topic_key` 추적)
  2. 생성된 제목이 기존 글과 같으면 발행하지 않고 다음 주제로 재시도
  3. AI 생성 실패 시 템플릿 폴백 발행 금지 (기존 중복 글의 원인이었음)
- 주제 풀 수정: `lib/archive-auto-publish.ts`의 `AUTO_PUBLISH_TOPICS` 배열
- **필요한 설정**: Vercel 환경변수에 `CRON_SECRET` (또는 `ARCHIVE_CRON_SECRET`) 등록
- 수동 테스트: `GET /api/archive/auto-publish?dryRun=true` (Authorization: Bearer <secret>)

## 2. 기존 중복 글 정리

샌드박스에서 DB 접속이 안 되어 로컬 실행 스크립트로 제공:

```bash
node scripts/cleanup-duplicate-archive.mjs          # 미리보기
node scripts/cleanup-duplicate-archive.mjs --apply  # 실제 반영
```

- 같은 제목 글 중 최신 1개만 남기고 나머지는 `archived` 처리 (삭제 아님 → 복구 가능)
- 화면단에도 같은 제목 최신 1개만 표시하는 안전망 추가 (블로그·자료실 공통)
